# 選角及入房規則

## 電腦局（已接入公開流程）
選場 → 四角色選角 → 確定玩家角色 → 其餘三角色由 BOT 入座 → 開局。

四隻角色各一，不會重複。BOT 打法／難度與外觀分開。選擇會保存作下次預設；已有對局的續局優先沿用該局角色。

bot-ready.png：實際電腦局準備畫面。

## 真人房間（介面與共用房間程式已備妥，公開配對尚未接線）
第一位真人入房便開始全房共用 30 秒。後加入者沿用剩餘時間，不會重設。期間隨意換角、允許重複角色，不用鎖角／按準備；0 秒使用每人的當前待定角色，空位由 BOT 補齊，統一開局。四位真人提早到齊亦等滿倒數。

human-room-design.png：CharacterRoom 實際元件的介面示意，使用測試房間資料；兩位真人可同選國王兔。這張圖不是已上線真人連線的證明。

角色以暱稱、自己／真人／BOT 標記及東南西北座位區分。進入牌局後角色固定，斷線及 BOT 接管不改角色。
