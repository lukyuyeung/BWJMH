# BUNNY GALA · 完整牌桌設計規格

## 本次交付與狀態

完整牌桌概念圖、完整前臂概念圖、紅蘿蔔立直棒透明 PNG 素材表、六款 CUT-IN 設計規格、中央面板互動預覽原始碼，以及已加長衣袖的手部 3D 預覽原始碼。

這是供下一次遊戲更新使用的設計與預覽包，尚未接入正式遊戲。概念圖不是已拆好的動畫素材；紅蘿蔔 PNG 是含多個方向的素材表，尚未逐支裁切。舊版 GLB／Blend 未隨本次重製，不可當作新版完整手臂模型。

## 中央面板

- 中央核心只顯示場風／局數與餘牌，例如「東 3 局」「餘牌 42」。
- 四個方向顯示各家自風與點數。風位依莊位變動，不與畫面方向永久綁定。
- 莊家用金色「莊」標記；當前行動玩家用青綠色外框與文字提示，兩者獨立。
- 本場與供託總棒數放牌桌角落資訊列，不放中央核心。
- 點數使用等寬數字；狀態變更不引發面板尺寸改變。

## 框邊紅蘿蔔立直棒區

- 中央面板外框四邊各一個凹槽，與該方向玩家對應。
- 上下槽橫向、左右槽縱向；不壓住風位、點數或牌河。
- 未立直：空槽。已立直：放入一支紅蘿蔔棒，顯示「立直」。
- 棒身橙色、葉帽綠色、淡金嵌線，細長輪廓適合狹長槽。
- 遊戲中以權威狀態切換，棒數與供託同步；互動預覽的按鈕只作示範。

## 手掌與完整衣袖

- 同一連續結構：兔掌 → 手腕 → 羅紋袖口 → 長前臂衣袖 → 畫面外。
- 沿用現有參考約三至四張牌闊的掌部尺寸，以牌寬作尺度，不以固定螢幕像素硬編。
- 這是參考比例目標，未量測到雀魂同一相機下的精確像素比。接入遊戲時需用實際相機與出牌距離對齊。
- 袖身末端必須始終在視錐外；伸至最遠落牌點、收手、四個座位及直橫畫面均檢查。
- 不允許掌部浮空、不允許袖口與手腕分離、不允許短袖身末端露在桌內。
- 動作：由座位邊界外進入 → 落牌接觸與放手 → 沿原方向整臂退場。
- 現有預覽將長衣袖接到原袖身，掌部比例未縮小。這是預覽程式幾何修改，未輸出新版 GLB。

## 座位 CUT-IN

- 六種：碰粉紅、槓紫色、吃青綠、和橙紅、立直香檳金、自摸橙金。
- 四層：斜切色帶／角色／文字／前景特效。角色超出色帶上緣。
- 相同動作在四個座位使用同一尺寸，不因左右座位而縮短或壓縮。
- 立直／自摸的每個字與單字動作同高；加寬文字區與色帶，不縮字。
- 同一動作使用同一字區版型及色帶長度；不同角色以角色錨點適配。
- 跟隨行動者的座位錨點，不橫跨全桌、不使用 DIM。
- 碰撞時平移整組或調整安全邊距，不截斷色帶；保留中央面板與手牌可讀性。

## 接入與播放效能

- 對局開始前預載素材，圖片完成 decode，模型完成解析；預先建立與暖機材質。
- 動作觸發時重用物件與動畫，不臨時下載、解析模型或編譯材質。
- 動畫由時間軸驅動，不等待完整動畫才處理權威牌局更新；低效能模式減少粒子。
- 更新遊戲時量測首次與連續播放的延遲、掉幀及四座位鏡頭裁切，不能用概念圖代替效能實測。

## 設計包使用

- artwork/：完整牌桌、完整手臂、紅蘿蔔素材表、立直與自摸細節圖。
- preview/：中央面板及手部預覽頁，含本地 Three.js 相依檔。
- 在解壓縮根目錄啟動靜態 HTTP 伺服器，再開 preview/index.html。手部頁使用 ES module 與 fetch，不適合直接以 file:// 開啟。
- 手部預覽已通過 JavaScript 語法檢查；本次環境未進行 WebGL 瀏覽器畫面驗證。
