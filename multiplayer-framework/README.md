# 真人模式架構待檢查資料

此資料夾用來接收 Bunny Gala 真人模式框架（bunny-gala-kit-0.18），供後續檢查及整合評估。此 README 僅建立上傳位置，不代表框架已上傳、審核、接入或部署。

## 上傳方式

建議先在電腦解開 ZIP，再把原有目錄結構上傳到此資料夾。請保留套件自身的 README（放在其原有子資料夾，避免覆蓋本說明）、文件、原始碼、範例、package.json、lockfile、測試及 check 工具。大型 ZIP 也可放在這裡，但解壓後的程式碼較方便逐檔檢查。

不需要上傳 node_modules、編譯快取；不要上傳 .env、私鑰或存取憑證。

## 待核對項目

- 多人桌空位 Bot 能否完整完成對局、合法和牌及繼續下一局。
- actors() 的多座位回應、吃碰槓榮和優先序及多家榮和規則。
- 紅蘿蔔開局鎖款、最大虧損、房間 300 單位限制的實際定義及派彩守恆。
- 平台一場與日麻一局／東風戰／半莊的對應。
- turnMs、斷線重連、30 秒逾時後持續摸切及取回控制。

以上是待驗證的問題清單，不是已確認的框架缺陷。上傳後通知此對話，再從 GitHub 讀取實際內容進行檢查。
