# 共用元件

每款遊戲的返回鍵、橫屏和音效都要用平台這一套，玩家在每款遊戲才會有一樣的手感。**不要自己另外做。**

## 返回鍵 `@bunny-gala/contract/back`

```ts
backButton(onBack: () => void, place?: { label?: string; top?: number | string; left?: number | string; size?: number | string; inside?: HTMLElement | null } | string): HTMLButtonElement
```

- 左上角的金色方形返回鍵，每款遊戲都一樣。每頁呼叫一次。
- `top`、`left`、`size` 用來對齊你自己的頂列：上邊距和大小請和右上角按鈕一致，才不會重疊。預設是 10px / 12px / 44px。
- `inside`：放進某個元素裡（絕對定位），畫面會跟著縮放的版面用得到。
- 大廳：`backButton(leaveToHall)` 回到 Bunny Gala 首頁。
- 牌桌：回到你的大廳；離開時這一手會由 `fallback` 代打完。
- 改完版面後，請在 812×375 下檢查有沒有重疊。

## 回首頁 `@bunny-gala/contract/shell`

```ts
leaveToHall(): void
```

在 App 裡、網頁版、或被包在別的頁面裡，它都會用對的方式回到 Bunny Gala 首頁。練習平台上會回到 launcher。

## 橫屏 `@bunny-gala/contract/landscape`

```ts
landscapeOnly(): void
```

整個 Bunny Gala 只支援橫屏。每一頁（大廳、牌桌）一開始就呼叫：能鎖的裝置會鎖橫屏，不能鎖的會顯示「請把手機轉橫」。

## 音樂與音效 `@bunny-gala/contract/audio`

```ts
playMusic(url: string | null, volume?: number): void            // 背景音樂，同時只有一首；null 停止
playCue(url: string, volume?: number): void                     // 音效
mountAudioSwitches(el: HTMLElement, labels?: { music: string; sfx: string; on: string; off: string }): void
musicOn(): boolean
sfxOn(): boolean
onAudioChange(fn: () => void): () => void
```

- 音樂和音效是兩個開關，所有遊戲共用同一份設定。
- App 切到背景時，聲音會自動暫停。
- 一定要用 `playMusic` 和 `playCue` 播聲音，玩家關掉開關才會有效。
- 設定面板裡用 `mountAudioSwitches` 畫兩個開關，樣式寫在你自己的 CSS（`.audio-row`、`.on`）。

## 牌桌連線 `@bunny-gala/contract/client`

```ts
playGame(game: GameModule, el: HTMLElement, conn?: Connection, opts?: { autoStart?: boolean }): Promise<void>
callApi<T>(conn: Connection, path: string, body?: unknown): Promise<T>
playConnection: Connection
```

- `playGame`：牌桌頁用它就夠了。
- `callApi(playConnection, "/v1/casino/games")`：大廳讀各房間的限額和能不能進。
- 只有畫面完全自己做連線的遊戲（像平台的德州撲克）才需要 `TableClient`。一般不用。
