# 第五課：立直！等到你的自摸

公開入口：`/?mode=bot&lesson=5`。固定教學牌局，非正式對局；無限時刮牌練習，正式對局仍最多十秒。

1. 介紹打出北後聽八筒／東，使用提示卡內的牌形例子。
2. 四項立直條件：門前清、聽牌、至少1000點、牌山至少四張。
3. 按立直，再選北；使用真正立直動畫、橫牌及1000點立直棒。
4. 南→西→北輪轉，自動摸入九索；刮開後不能和，自動摸切。
5. 再一圈自動摸入八筒；揭曉前隱藏自摸按鈕，揭曉後親手自摸。
6. 揭曉裏指示四筒→五筒；在真正結算頁解讀立直、門前清自摸、普通寶牌與裏寶牌，合計4番30符。
7. 三題總結；首次300體驗紅蘿蔔（瀏覽器本機），完成後前往第六課目錄。

提示卡避開手牌、刮牌、操作按鈕、牌河及結算役種區。可從各已完成小節續課，不改電腦局存檔。
