# 新手截圖教學冊 v1

公開遊戲右上「？」可隨時開啟。首次在本瀏覽器進入電腦局，會自動出現五步介面導覽，可跳過；關閉後記住已看過。教學冊共 12 章，每頁使用實際遊戲截圖、區域框線與簡短說明；可點按放大圖片。另附四組加一對的實際牌例與既有役種圖鑑入口。

- `table.jpg`：牌桌、手牌、牌河、中央局況、自動操作與寶牌位置。
- `inspection.jpg`：長按／掃牌查看牌河數量。
- `pon.jpg`：鳴牌與跳過。
- `riichi.jpg`：立直操作。
- `furiten.jpg`：聽牌與振聽。
- `tour-preview.png`、`book-preview.png`：手機橫向的實際教學介面。

圖片取自本遊戲的本地測試牌局，並非玩家私人對局。電腦局閱讀教學冊及役種圖鑑時暫停並補回倒數；真人局不會因個別玩家看教學而暫停。
