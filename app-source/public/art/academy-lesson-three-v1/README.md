# 第三課：怎樣才能和牌？

大廳新手學堂及第二課結尾可直接進入第三課。

流程：重溫四組加一對 → 形齊但無役的榮和反例 → 白發中役牌小題 → 親手榮和 → 真正役種結果 → 普通自摸 → 真正兩役結果 → 小測驗 → 一次性100體驗紅蘿蔔 → 第四課目錄。

無役反例是未立直的門前榮和，牌例123456萬、789筒、23索、東東，對手打出4索。實體14張可完成形狀，但無役，規則引擎不提供榮和。沒有用門前自摸作無役反例，因為門前清自摸本身是役。

正例：123萬、789筒、234索、白白、東東。對手打出白後按「和」榮和，只有役牌・白；另一副教學牌自動摸入白後，玩家按自摸，成立役牌・白及門前清自摸。兩個例子均無立直、不刮牌、不計寶牌；結果使用正式WinBanner與役種配音，不是模擬文字。番符點數在畫面如實顯示，本課只框出役名，第六課再詳教計分。

每個固定牌例均由同一副136張實體牌分配。教學不讀寫正常Bot存檔、不爭奪分頁控制權、不消耗正式錢包。只保存已完成小節，未完成小節重練。第一、二課資料保留；三課首次體驗獎勵總計300，重玩不再派獎。

第四課已上線，完成第三課後會直接進第四課，不會跳去電腦局。提示框與目標白牌、和牌按鈕、役種區分開；演出期間攔住背景操作。
