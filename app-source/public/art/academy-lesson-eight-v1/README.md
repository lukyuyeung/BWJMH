# 第八課：出牌與防守入門

公開入口：`/?mode=bot&lesson=8`。十四步、四個固定牌例，不計時。

- 二三萬搭子與孤立九筒：親手出牌。
- 長按二索、掃到六索：真實聽牌提示與抬起選牌動畫；放手不會出牌。
- 打六索後實際聽二索／五索，說明未見枚數不是牌山保證。
- 右方對手實際立直，點出其牌河九筒，再打自己的九筒，練習現物防守。
- 現物只對指定玩家安全；比較未聽牌防守與已聽牌仍需評估牌值、風險。

框線依手牌及3D公開牌河的真實位置投影，教學卡、框線與抬起的手牌互相避讓，無暗色遮罩。首次完成300本機體驗紅蘿蔔，八課累計2400，不重複派獎。完成按鈕接第九課目錄；第九課仍未開放。
