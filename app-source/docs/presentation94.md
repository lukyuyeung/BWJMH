# v94｜第八課：出牌與防守入門

大廳第八課正式開放，入口 `/?mode=bot&lesson=8`。十四個小節，四個固定牌例，不計時。第七課直接接第八課；第八課完成接第九課目錄，第九課仍尚未開放。

1. 保留二三萬搭子，親手打出本例的孤立九筒。
2. 長按並掃過二索、六索，比較實際聽牌提示；放手不會出牌。桌面滑鼠及鍵盤聚焦亦可查看。
3. 親手打出六索，真正聽二索／五索；剩餘枚數代表未見數量，不保證位於牌山。
4. 對手透過正常規則引擎立直、支付1,000點，觀察橫放九筒，親手點出牌河現物，再打出手中的九筒。
5. 現物只對指定玩家安全。比較未聽牌先考慮防守、已聽牌仍需比較牌值及風險；沒有宣稱聽牌必須進攻，或所有孤張都該先打。

每個教學牌局維持136張實體牌；宣告、出牌及聽牌使用原有引擎。錯選不會替玩家打牌。可從十四個檢查點重建進度，教學不覆蓋電腦局存檔。

框線從實際 DOM 手牌及 3D 牌河的投影邊界取得，不使用固定牌河猜測座標；資料僅包含公開捨牌。教學卡避開所有目標、中央牌河及下方手牌，聽牌提示上移以避開抬起的手牌框。沒有暗色遮罩。

首次完成100本機體驗紅蘿蔔，八課累計800；複習不重複派獎，沿用現有本機進度與獎勵機制。

驗證：規則核心、136張牌與14個檢查點重建；正式編譯手機／桌面／較小橫向手機的全課觸控操作、框線互不重疊及卡片避讓、斷點重載、舊七課資料遷移與獎勵冪等、電腦局存檔保持。日誌見 `qa-94`。
