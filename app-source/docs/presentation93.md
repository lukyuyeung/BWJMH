# v93｜無役、三種振聽與立直跳過

- 聽牌欄顯示自家牌河／同巡／立直後振聽原因；振聽牌面的剩餘枚數改為「振聽」。不能榮和仍可合法自摸。
- 無役按實際和牌評估判斷，含部分聽牌有役、部分無役；寶牌不充當役。無役與振聽可同時存在。
- 無役完成牌被放過也會進入同巡振聽，直到自己的下一次摸牌。被吃碰走的自己捨牌仍保留振聽歷史。
- 立直後保留榮和／跳過；跳過合法榮和會持續振聽到本手結束。自摸另有「跳過自摸」並摸切，該張自家捨牌形成振聽。
- 刮牌前不透露自摸按鈕或聽牌數；刮牌計時等待牌桌顯示，並預留操作時間。自動和牌留有短暫手動跳過時間。
- 第三至第七課同步修正文案，第七課明確演示無役與同巡振聽重疊。教學仍使用提示小框，不加暗色遮罩。
