# v105 · 開局前全素材預載

建置時產生帶SHA256指紋的全部媒體清單，涵蓋所有角色、表情、CUT-IN、滿貫至雙倍役滿、按鈕、牌面、字體、手部資源、配音、音效、音樂與影片。開局前使用4條併行請求下載到瀏覽器持久快取，依實際檔案容量顯示進度，全部成功後才進入牌桌。失敗保留重試，不把未載完誤標100%。

Service Worker攔截素材請求，包含帶版本query的網址；音樂／影片Range請求亦可由快取返回206，不重抓整部影片。指紋不變的檔案下次不用重下載，更新過的檔案會先刷新快取。只把目前需要的圖片及音效解碼進記憶體，避免一次解碼全部圖片／影片令手機耗盡記憶體。

首次完整預載約250MB，首次進場會較久；之後會驗證並重用快取。快取容量不足、網路失敗或瀏覽器不支援時顯示重試，不跳過素材。預載能減少首次網路等待，不能保證所有裝置解碼或渲染完全零延遲。

包含此前尚未發佈的v104修正。驗證TypeScript、正式建置、全清單下載完成才進場、離線圖片及影片Range命中快取。
