# v103 · 統一橫向操作

大廳、學堂、選場、選角準備房及牌桌共用橫向限制。直向時顯示覆蓋全畫面的轉橫提示，背景不可操作或捲動，Escape不能關掉提示；轉橫後保留原畫面與進度。

在支援的瀏覽器嘗試 Screen Orientation API 的 landscape 鎖定。「以橫向開始」透過使用者操作要求全螢幕再鎖定；全螢幕切換也會重新嘗試。加入 landscape/fullscreen app manifest。Safari等未提供方向鎖定API的瀏覽器保留手動轉橫提示，不假裝已鎖定裝置方向。載入頁內嵌iframe不建立重複提示。

驗證：中英文大廳／學堂／選角房的直→橫→直切換、背景阻擋、Escape保護、未支援API的按鈕後備路徑、支援API呼叫landscape、三個入口載入同一組資源、manifest方向設定，以及TypeScript與正式建置。

實際WebGL牌桌亦已驗證橫→直→橫後保持同一牌局、直向不能操作、回橫正常顯示，無重新載入或瀏覽器錯誤。
