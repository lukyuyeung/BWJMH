## 已修正

1. **頭像失敗會阻擋整張牌桌開局。** 中止黑帽T頭像下載即可重現 startup error。頭像／莊家徽章改為非開局門檻；牌桌與必要牌面仍保留原有載入驗證。失敗頭像隱藏破圖，保留玩家名稱。修正後同一網路故障測試能開局，手機亦可逾時後取回控制。
2. **WebGL 恢復後備用輪詢沒有停止。** 原 fallbackFrame 每 50ms 持續安排下一次，即使已回到 WebGL，仍會重複釋放動作鎖。現在只在 fallbackActive 時執行，context restored 會取消計時及停用待執行回呼。已實際觸發 WebGL context loss/restore，確認回復 3D 後輪詢停止且無 JS 錯誤。
3. **歷史驗收腳本已落後目前產品。** tiers60 把流局滿貫錯當作必有和牌 result；multiplayer58 仍等候已移除的雙響分頁按鈕／舊終局容器。改為檢查流局結算與現在的逐家報役流程。這些是驗收腳本失效，不能當成遊戲故障。
4. **接入文件有過時聲明。** 更正「配音未生成／音量未接」等已完成項目，保留真人服務、錢包和真機驗收的未完成狀態。
