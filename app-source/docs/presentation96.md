# v96｜新手學堂英文版與文字框適配

第一至第八課加入完整英文課文、題目、答案、操作回饋、獎勵及控制器錯誤訊息。大廳課程卡、第九課設計預覽與完整英文設計文件同步提供英文。

沿用遊戲的 EN／ZH 語言設定，課內另提供可直接操作的語言切換。切換不重設手牌、步驟或獎勵。第九課仍是設計預覽，不新增互動課程。

英文採用精簡、完整保留規則的文案；標題、內文、答案、表格及按鈕依現有提示框換行，沒有靠截斷或隱藏文字處理。提示卡維持避開手牌、牌河、聽牌欄及操作目標，無暗色教學遮罩。

統一 Closed Tsumo、Half Flush 等課內與結算名稱。補齊無役、三種振聽、刮牌教學狀態及牌桌座位尾綴，避免中英混雜。麻將牌面的標準漢字維持原有牌面。

仍為每課約2分鐘，首次300體驗紅蘿蔔，複習不重複派獎。

驗證：課程字串與控制器回饋的精確英譯覆蓋；92個教學檢查點的英文提示框、文字邊界與目標避讓；正式編譯桌面關鍵頁、實際刮牌與自摸／吃碰槓／跳過動作；手機完整第八課流程及課中雙語切換保持狀態；三種尺寸的大廳與第九課英文預覽。詳見 qa-96。
