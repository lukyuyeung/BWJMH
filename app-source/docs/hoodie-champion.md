# 黑帽T兔 — 終局預覽角色更新

2026-10-26：按玩家要求，終局設計預覽中的金帽兔改為黑帽T兔。以既有國王、忍者、巫師去背素材為風格參照，生成同一方塊比例、材質與工作室光影的獨立角色：象牙白兔臉、黑色帽T及連帽、粉紅耳內、胸前紅蘿蔔圖案。新圖為 1254×1254 RGBA，Alpha 範圍 0–255，沒有椅子或影片背景。
