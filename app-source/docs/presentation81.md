# Academy lesson one

Lobby now has a New Player Academy entry. Only course one is available; later courses are explicitly marked coming soon. First lesson has a welcome, four area-recognition tasks, real held-pointer tile inspection, one quiz, completion and optional beginner Bot entry. Checkpoints are saved after each step and completed lessons replay from the beginning.

The actual existing game renderer and inspection hook are used with a fixed physical 136-tile teaching board. Lesson transport cannot restore or save ordinary Bot games, claim their active-tab owner, consume their session, execute game actions or advance Bots. Normal automation and first-visit intro are excluded. HUD controls remain inside the teaching stage for wide phones; region layout is measured before paint, and the explanation is placed in a non-overlapping position. Transparent target buttons let players identify regions without changing settings. Only inspection passes pointers through to the actual hand. A hold across at least two tile IDs followed by release is required to proceed.

The isolated local learning ledger awards 100 DEMO carrots once. Balance is derived from completion, so retries/reviews do not add another reward. Storage failures do not show a successful claim. It is labelled as browser-local demo credit, not an authenticated wallet; production token settlement still needs server integration. Completion marks the older interface intro seen, while manual help remains available.

Checks: unique 136 physical tiles, 34 faces x4 and valid hand sizes; actual mobile and compiled-production flows; gold-frame containment of actual target regions; explanation/target non-overlap; interrupted progress resume; native touch count 3 then 0; no discard; quiz; repeat claim balance remains 100; original Bot save, owner and session are preserved; desktop non-overlap and held mouse inspection; quota failure/review reward tests. Production exposes no developer QA API.
