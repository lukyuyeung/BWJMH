# 新手學堂 · 第一課

大廳 → 新手學堂 → 認識你的牌桌。

流程：認識自己的手牌、牌河、中央局況及自動操作列；實際長按掃過兩張手牌查看牌河數量；完成小測驗；領取首次 100 體驗紅蘿蔔。可以離開後繼續；重溫不重複派獎。

使用同一套實際 3D 牌桌與長按檢視動畫。教學是獨立牌局，無倒數，不出牌，也不改動既有電腦局存檔與分頁控制權。闊屏教學時將 HUD 保持於完整教學畫面內，讓框線與操作區一致；一般對局排列不變。

提示卡會依目標位置放於上方或下方。手機及桌面均測試了目標框與提示卡不重疊，手機亦驗證金框完整涵蓋實際區域。

獎勵是此瀏覽器保存的體驗紅蘿蔔，不是正式錢包入帳；正式錢包未接駁。完成紀錄同時記住已認識介面，進入電腦局時不會再重複自動導覽；右上「？」仍可重看教學冊。
