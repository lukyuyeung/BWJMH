# 四級選桌插圖系列

## 01 新手場 · 小丑兔迎新

![新手場小丑兔選桌插圖](01-beginner.png)

依使用者提供的像素小丑兔設計：紅色爆炸頭、白色臉、藍色眼妝、紅鼻與笑嘴、藍白條紋服裝、深紅吊帶及綠色氣球。轉化為 Bunny Warriors 的立體像素角色風格。

場景使用溫暖、親切的翡翠黑金休息區，十三張厚身黑金牌背麻雀以4＋4＋5排列。此圖不內嵌場名、價格或UI，供中英文選桌卡片共用。

對應新手場入場設定1,000紅蘿蔔。此為插圖審閱版，尚未套用到公開版選桌卡片。

其餘三張（中級、高級、雀聖）待後續角色與方向確認；沿用同一橫向比例、牌面材質及系列構圖，再逐級提高場景氣勢。
