# 四級選桌插圖系列

## 01 新手場 · 小丑兔迎新

![新手場小丑兔選桌插圖](01-beginner.png)

依使用者提供的像素小丑兔設計：紅色爆炸頭、白色臉、藍色眼妝、紅鼻與笑嘴、藍白條紋服裝、深紅吊帶及綠色氣球。轉化為 Bunny Warriors 的立體像素角色風格。

場景使用紫金霓虹、水晶吊燈及奢華賭場氣氛，背景沒有兔子或其他品牌標誌。十三張厚身麻雀緊密排成一整列，不留分組空隙；黑色牌背只有簡潔金邊，沒有Logo或中央圖案。此圖不內嵌場名、價格或UI，供中英文選桌卡片共用。

對應新手場入場設定1,000紅蘿蔔。此為插圖審閱版，尚未套用到公開版選桌卡片。

中級場已完成巫師兔版本；高級、雀聖待後續角色與方向確認。全系列沿用相同橫向比例、背景及牌面材質。

## 02 中級場 · 巫師兔

![中級場巫師兔選桌插圖](02-intermediate.png)

依照「其他地方都不變」，只將新手場的小丑兔換成巫師兔：紫色尖帽、彩虹耳內及眼部、白色長鬍鬚與紫袍。保留紫金背景、綠氣球、原構圖、無標誌環境，以及緊密排列的十三張無圖案黑金牌背。

對應中級場入場設定10,000紅蘿蔔。此為插圖審閱版，尚未套用到公開版選桌卡片。
