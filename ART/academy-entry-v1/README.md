第二版：忍者兔轉向觀眾，清楚露出白色眼罩區及雙眼；枱面三組手牌全部改為黑金牌背朝向觀眾。黑板與老師手持的教學牌面保留。

公開版 v99 已採用本圖的最佳化 WebP 作為大廳入口；新手學堂、BOT 對局及 VS 玩家並排同一行。
