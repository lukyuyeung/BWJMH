# 第二課：自動摸牌與出牌

第二課已實裝，從大廳新手學堂或第一課完成畫面進入。沒有摸牌按鈕。

1. 認識萬、筒、索與字牌，完成四題辨牌。
2. 觀看下家→對家→上家→自己的逆時針回合。其他三家實際摸打後，系統自動替玩家摸入三萬，13張變14張。
3. 第一次指定短按北，實際打進自己的牌河，回到13張。明確說明這是操作練習，不代表北一定要打。
4. 用獨立答題盤辨認順子、刻子、一對；字牌不能組順子。
5. 再做兩輪少提示練習：其他三家自動摸打，輪到玩家自動摸牌；玩家可打任一合法牌。
6. 通過14→13張小測驗，完成後可領一次300體驗紅蘿蔔，再直接前往已上線的第三課；不會提前引導去電腦局。

牌局由同一副136張實體牌分配，使用正式規則引擎的摸牌、出牌與回合推進。教學隱去本課未教授的吃碰槓／和牌操作，對手的搶牌回應自動略過。無倒數，不改動原有電腦局存檔、分頁控制權及重連資料。

每個已完成的小節會保存；未完成小節重新練習，未保存中途任意牌桌狀態。第一課的舊進度會保留；兩課首次獎勵合共600體驗紅蘿蔔，只在本瀏覽器保存，不是正式錢包入帳。

固定初始手牌：1m 2m / 4m 5m 6m / 7p 7p / 2s 3s 4s / E E / N。初始13張，先從下家回合示範；玩家三次自動摸牌依序3m、9s、4p。
