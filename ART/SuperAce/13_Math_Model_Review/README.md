固定下注20，4組獨立種子各250000次付費牌局；完整計入觸發的免費回合與追加。RTP估計 **96.55325%**，蒙地卡羅近似95%信賴區間 **95.55%–97.56%**。此為估算，不是已認證理論值，也不是每次遊玩的回報承諾。

符號改為按列固定權重；合資格普通牌金牌率3%、CARROT每牌位2%、金牌轉換時惡魔10%。玩法倍率及賠付表沿用本試玩版。

小額校準發現下注0.01在逐筆兩位小數結算下會失真，故新接受下注以0.2為單位；這使最低0.05倍賠付仍能精確到0.01蘿蔔。餘額0.1%加減及比例快選按0.2取整，10%上限向下取至可用單位。111M等精確輸入保留；不是0.2倍數時明確提示，不能靜默改掉輸入。

已開始的牌局繼續重播其保存結果，不重新抽牌或重複派彩；之後接受的新牌局帶模型版本標記。既有餘額保留，沒有重設。

## 驗證

25項單元測試通過，包括固定權重分佈、金牌／CARROT頻率、最低下注與20下注的牌位及派彩同比例、下注上限與恢復冪等。瀏覽器確認新模型生效、0.01被拒而0.2可選、RTP說明可見、舊模型中獎3仍派3、重新整理不再派一次。六種手機尺寸及Auto版面通過。
