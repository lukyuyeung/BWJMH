## 交付界線

- 這批不是把原有整張分鏡改名，而是獨立牌面、部件、畫面或字體套件。
- 功能畫面的layout檔是獨立版面稿；底板、按鈕、開關等另有元件檔，layout本身不等於可編輯的分層PSD。
- WILD/CARROT部件各有獨立檔，但不同原生尺寸仍需共同畫布校準，不保證直接疊上就對齊。
- 金牌前景需與普通牌精準疊圖核對；不可因這批有金牌PNG就視為角色位置完全未變。
- 新增按鈕狀態與橫屏變體會存於原項目資料夾；是否已有檔案以manifest及QA紀錄為準。
- 48個動畫分鏡仍需要正式時間軸、可播放動畫及整合驗證，沒有以單張圖冒充動畫完成。
