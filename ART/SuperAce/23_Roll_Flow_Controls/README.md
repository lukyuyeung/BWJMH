## 聲音

依使用者最新要求簡化，取代前面音效指南與疊加版本：

- 待機嘗試播放完整intro，再進入lobby循環。瀏覽器限制自動播放時，首次觸控或鍵盤操作後解鎖；沒有增加確認視窗。
- 普通局只播reel_spin。中獎時換一段對應級別的中獎音樂，每局只播一次；根據已提交的該局總獎勵選曲，不改結果或RTP。
- 移除賺錢聲、數字聲、金牌/WILD聲、倍率聲、停牌/洗牌聲、操作提示及角色配音。遊戲不再把多段提示疊在同一局。
- 取消固定300/450/850ms截短。roll、普通贏獎、大獎曲目自然播完；新一局或重要轉場需要換曲時才柔和淡出，不為音訊延遲畫面或派彩。
- 免費進場、追加及結算保留單段主題；音頻原檔均保留在獨立試聽頁。

## 免費次數

已把免費次數移到roll按鈕正下方，移除按鈕上的「開始免費」。等待畫面為「免費10次・待開始」，開始後逐局顯示「免費10次」至「免費1次」。計數包含正在進行的免費局，最後一局不會變成「最後免費局」或提前顯示0；結算完成隱藏。原先每次10局及加5局規則不變。

## AUTO／速度

![獨立圖示](04-independent-icons.png)

`icons/`有獨立透明原PNG、裁切SVG、256px WebP及實裝的button WebP：

- AUTO：金色循環箭頭包播放三角。
