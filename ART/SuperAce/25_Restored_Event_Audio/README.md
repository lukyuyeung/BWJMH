## 新檔與混音

- `user-originals/`保留使用者上載原WAV，兩段各2.5秒；遊戲使用對應AAC/M4A顯示檔。
- 音頻網址包含原檔SHA256前綴，目錄記錄完整SHA256，避免瀏覽器仍播放舊Joker。
- ROLL、主要中獎音樂與玩法SFX採獨立通道；中獎曲不再把整組SFX擋掉。SFX最多3個，使用峰值壓縮與優先級控制，沒有為避免重疊而刪掉整類音效。
- Joker只在真正翻出時觸發，惡魔之後複製出的牌不重複叫聲。金牌翻面與Joker兩個節點皆保留；不使用固定幾百毫秒裁短新檔。
