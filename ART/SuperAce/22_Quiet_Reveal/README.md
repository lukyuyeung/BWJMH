# 金牌與第一個CARROT出現時不播提示聲

依使用者最新要求：

- 取消初次發牌與連鎖補牌時的golden_card出現提示音。
- CARROT出現音效改為依已揭示數量判斷，第一個不播；不使用尚未揭開的整盤CARROT總數誤判。
- 第二個之後的提示、兩個CARROT且仍有後續列的期待聲、三個觸發免費遊戲的聲音保留。
- 金牌中獎變身與WILD事件仍使用原音效；普通背景音樂仍按較疏落的混音播放。

固定種子1確認第一個CARROT有顯示而沒有scatter提示音；種子72確認金牌沒有golden_card提示音，但golden_eliminate變身音效仍觸發。兩局派彩分別保持餘額2000及2028。
