# 第四課：寶牌是甚麼？

大廳及第三課結尾可直接進入第四課。

1. 在實際牌桌找到左上的寶牌指示牌，區分「指示牌」與「真正寶牌」。
2. 數牌下一張與九接一小題。
3. 風牌東南西北循環、三元牌白發中循環小題。
4. 指示四萬，遊戲會以閃亮動畫提示真正寶牌，親手從手牌選出普通五萬；只選牌，不出牌，顯示一枚寶牌。
5. 換赤五萬例子：仍當五萬；指示四萬時同時計寶牌＋赤寶牌兩枚；其他指示牌時赤五仍獨立加一番。
6. 真正反例：完整牌形且有一枚寶牌、一枚赤寶牌，但零役，規則引擎不提供榮和。
7. 真正白牌榮和：役牌・白提供一個役，寶牌一番、赤寶牌一番，實際結果共三番。
8. 小測驗、一次性300體驗紅蘿蔔，再到第五課目錄。裏寶牌與立直留待第五課，槓相關進階情境後續再學。

固定牌例全部由136張實體牌分配；真正選牌、榮和及結果計算使用既有引擎與WinBanner。寶牌不會被寫成一個役，沒有把寶牌番數當成合法和牌條件。

每個已完成小節保存，未完成小節重練；不讀寫普通Bot存檔、不搶其分頁控制權。舊前三課進度保留，四課首次體驗獎勵合共1200；重玩不再派獎。這是本瀏覽器保存的體驗獎勵，並非正式錢包入帳。

提示與指示牌、手牌、榮和按鈕和結果列分開，手機及桌面均作完整流程測試。第五課尚未實裝，目錄會清楚標示準備中。
