# Art 預覽

新 Art 必須先提供 GitHub 預覽連結，等用戶確認後才接入遊戲。聊天圖片輸出及 `/workspace` 本機連結在用戶介面未必可見。

- [四家牌河：固定玩家座位整體視角（待確認）](mahjong-rivers-player-view-overview.png)
- [四家牌河：排列、厚度及前後遮擋細節（待確認）](mahjong-rivers-four-seats-details.png)

牌河預覽各家以每行六張、三行共十八張示範。玩家在下、對家在上、上家在左、下家在右。全部平放於同一枱面，每家牌面方向跟該玩家座位轉向，保留合理接觸陰影、厚度及行列間距。

重複「二萬」只為比較方向及外形，並非真實牌局。圖像是美術示意；實際遊戲仍須用同一個 3D 模型及固定鏡頭校準物理尺寸、透視、點擊位置和枱面接觸，不會把示意圖中的牌或牌面直接當作遊戲資料。

本資料夾不由遊戲載入。加入預覽圖不代表用戶已批准整合。
