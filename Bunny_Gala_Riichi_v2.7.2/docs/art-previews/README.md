## 完整牌枱構圖預覽（待確認）

[查看完整牌枱：建議玩家視角](gala-full-table-player-view-preview.png)

沿用金銅圓角枱框、深綠花紋絨面、中央八角枱心、紅絨金椅及西裝像素兔。建議構圖為玩家座位上方約 55 度俯視，優先讓對家及左右兩家牌河清楚可見，同時保留近枱邊的玩家視角。

本圖含四家牌河（各六張一行、兩行）、玩家十三張手牌及分開的一張摸牌、對家暗牌、剩餘牌山及簡化副露示意。牌河重複二萬方便比較方向，副露及牌面只供構圖示意，不代表真實牌局或合法牌張分配。

這是依照參考圖生成的美術構圖，並非遊戲引擎截圖或相機參數的精確測量。用戶確認後，接入前仍須以同一個 3D 麻雀模型驗證各家實體尺寸、相機透視、遮擋、牌河方向、牌山上下層、實際副露及枱面接觸。這次只新增預覽，不修改遊戲。

## 四邊同時有剩餘牌山：擺位示意（待確認）

[查看四邊牌山與手牌、牌河的分區](gala-four-walls-spacing-preview.png)

這次只驗證四邊同時有剩餘牌山時的擺位。由每名玩家座位朝枱心方向，依次是：站立手牌 → 間距 → 平放的兩層牌山 → 間距 → 平放牌河 → 枱心。圖中四家各用一行六張棄牌方便比較，側家站立暗牌與平放的雙層牌山分開呈現。

檢視重點是近家牌山是否遮住自己的牌河，以及對家、左右兩家的三個區域是否清楚分開。牌山段長、重複牌面及牌數只作構圖示意，不代表真實牌局、固定剩餘牌數或可直接量取的相機規格。這張圖未接入遊戲；不擴展到副露或其他功能，先等用戶確認這個場景。

## 六項要求：四家最大容量的 3D 排位示意（待確認）

[查看完整容量排位圖及下方三組近鏡](gala-max-capacity-17-stacks-24-discards-preview.jpg)

本圖以固定 3D 模型逐隻排列，沿用原本賭枱背景。這次只產生預覽及其獨立可重現模型，沒有接入遊戲或修改遊戲程式。

1. 四家牌河共用名義比例 88×120×56（模型單位）的麻雀塊，牌底、黑色底層與細金接縫屬同一總厚度，並附近鏡。
2. 四家各預留一處紅蘿蔔立直棒空間，粉紅虛線示意預留範圍。玩家放於手牌右方綠毯，避開牌山及手牌遮擋；其他三家在牌山與牌河之間留位。
3. 每家牌河完整放滿六張一行、四行共二十四格作容量驗證，不再只畫一行。
4. 按本輪用戶指定：玩家牌山每幢維持方向；對家與左右兩家每幢相對該模型轉九十度，並附比較近鏡。這是本輪待確認的擺法。
5. 四邊均完整放滿十七幢，每幢上下兩層，共三十四張；上層以 01–17 標號方便核對。
6. 玩家手牌基底在綠色枱面內，牌身與枱面成九十度直立，透視角度由鏡頭決定；不把牌擺在金框上。

**容量壓力示意，不是真實牌局。** 各家同時放滿最大的牌河、牌山及手牌，目的是驗證預留區域，不能作為同一副 136 張牌的實際快照。圖中沒有新增遊戲操作或修改本來牌局規則。

[模型數量、層高、牌底及預留區域驗證資料](capacity-model/geometry-checks.json)。`capacity-model` 內的獨立預覽來源不由遊戲載入。可從專案根目錄執行 `node docs/art-previews/capacity-model/render.mjs`，輸出至 `/tmp/bunny-capacity-preview`，或以 `QA_OUTPUT_DIR` 指定輸出位置；需要已安裝專案依賴及 Chromium。
