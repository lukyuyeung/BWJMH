# 滿載修正版 V11

[完整手牌](full-hands-clean.jpg) · [四組明槓](four-kans-clean.jpg) · [手牌分區](full-hands-zones.jpg) · [明槓分區](four-kans-zones.jpg)

本輪實際修改預覽模型與構圖，不只是列問題。仍遵照先展示美術、再整合正式遊戲的流程；遊戲主程式尚未套用。

## 已改動

- 將桌面平面與立面投影分開校準，立面高度不再跟著桌面被壓扁；三家暗牌恢復直身，側家暗牌稍向內轉，保持牌面隱藏。
- 統一牌身 100 × 136 × 44，沿用已認可牌面，縮減過厚的原 64 厚牌身；牌山仍為實際上下兩層。
- 增加可辨識的金色收邊、維持中性牌面照明與文字對比；平放牌增加接觸陰影。
- 桌面座標由 3000 調整為 3400，保持背景桌面在畫面的占比，重新分配各帶。副露帶 1600、牌山 1300（玩家 1320），拉開對家副露與牌山。
- 暗牌與副露交界增加間隔；副露情境中的三家殘餘暗牌再往端部移 220，修正側家暗牌遮住第一組明槓。
- 玩家手牌沿用獨立直身牌面展示，兩張殘餘手牌放左邊，避免遮住自己的副露。
- 調整背景對家角色大小，使其頭部更接近左右角色；保留原桌、座椅與三個半身角色。對家分數卡移近角色。
- 保留河前實色蘿蔔棒、四方座風、局目、剩餘張數與寶牌區。

## 驗證與限制

四張圖重新由 Chromium 渲染，逐家確認 24 張牌河、17 幢兩層牌山；明槓情境每家 16 張副露。桌面範圍、模型交疊、接觸高度、每個公開牌面九點對其他牌身遮擋、資訊區及蘿蔔棒遮擋均通過。獨立手牌展示層另以成圖目視核對，不把世界座標檢查當成展示層檢查。

這是容量壓力預覽，不是合法的同一副 136 張實戰牌局。中央餘牌數只示範資訊樣式。桌面版已渲染，電話版及實際點牌操作不在此獨立預覽的驗證範圍。材質觀感仍由預覽圖確認，數據通過不代表美術已獲認可。
