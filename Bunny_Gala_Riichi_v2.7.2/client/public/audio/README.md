# Bunny Gala audio

Upload game audio into:

- `music/` — background music.
- `voices/` — character voice recordings; use yellow/, wizard/, ninja/, king/ subfolders.
- `sfx/` — tiles, calls, interface and scoring sound effects.

Use lowercase filenames with hyphens, preferably MP3. Extract ZIP archives before uploading. Files here are publicly visible on GitHub and become public assets when deployed. Uploading files does not automatically connect playback to game events.
