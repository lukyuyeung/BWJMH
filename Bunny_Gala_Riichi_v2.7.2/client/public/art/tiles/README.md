# Bunny Gala 麻雀牌面

本資料夾是遊戲實際載入的牌面資源，沿用已確認的象牙白、紅黑綠色琺瑯風格。來源是 `docs/art-previews/tile-set-v1` 及 `table-design-v2` 的設計，已轉成正面平面貼圖。

| 檔案 | 排列 |
| --- | --- |
| `characters-atlas.png` | 3 × 3；一至九萬，逐行由左至右 |
| `circles-atlas.png` | 3 × 3；一至九筒，逐行由左至右 |
| `bamboo-atlas.png` | 3 × 3；一至九索，逐行由左至右 |
| `honors-red-atlas.png` | 5 × 2；上排東南西北白，下排發中及赤五萬、赤五筒、赤五索 |
| `peacock-1s.png` | 孔雀一索透明原圖，遊戲一索優先使用此檔 |

`client/src/tile-art.ts` 統一處理 34 種基本牌及 3 款赤五的對應，供 WebGL 牌面、DOM 備援牌面、役種例子和結算畫面共用。二索使用收窄的 UV 範圍，避免旁邊孔雀圖案進入裁切範圍。

牌面身份及赤牌標記只由遊戲資料提供；圖片不包含手牌資訊或對局結果。圓角牌身、黑色背層及金接縫是 `tiles3d.ts` 的實體模型，沒有將照片中的透視、厚度或枱面背景貼到遊戲中。

牌面保留圖案本身的琺瑯光澤，用不受場景高光洗白的材質呈現；邊緣及牌背則接受場景燈光。
